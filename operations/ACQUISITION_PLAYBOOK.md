## 失敗パターンの予防

| 失敗パターン | 予防策 |
|---|---|
| 投稿が機械的すぎてフォロワーが離れる | 自動投稿の品質を毎週レビュー、手動投稿を週5本以上 |
| 占い結果に対するクレーム | エンタメ目的の明記を徹底、断定表現を避ける |
| 「当たらない」と言われる | LINEウェルカム+各鑑定文末に「参考までに」と添える |
| 投稿が炎上する | 政治・宗教・他者批判は絶対避ける |
| BANリスク | 各プラットフォームの規約を半年に1回見直し |

3. **競合リサーチ**
   - 他のAI占いBotの動向

4. **施策の継続/中止判断**
