# セレネ 30日 SNSコンテンツカレンダー

毎日3投稿（朝・昼・夜）× 30日 = 90投稿のテンプレ集です。
- **朝(7時)**：今日のテーマ／星座運勢
- **昼(12時)**：占術知識ミニ講座／占術トリビア
- **夜(21時)**：自己肯定メッセージ／明日への準備
- **CTA**：3投稿に1回、LINE友達追加を促す

各投稿はXとThreads両方を想定。Instagram/TikTokは画像/動画追加で流用可。

## 投稿のコツ

### ✅ やる
- 1投稿1メッセージに絞る（情報を詰め込みすぎない）
- 「あなた」を主語にする（読者の物語にする）
- 具体的な行動を1つ提示する（深呼吸3回、感謝3つ、など）
- 朝は希望、昼は知識、夜は癒し のトーン分け

### ❌ やらない
- 「絶対」「必ず」「100%」を使う（景表法リスク）
- 医療・法律・投資の助言（規制リスク）
- 他者批判（炎上リスク）
- AI生成丸出し（オリジナリティで差別化）

## n8n自動投稿ワークフローのイメージ

```
[ Cron: 毎日7:00, 12:00, 21:00 (JST) ]
       ↓
[ Get current date / day of week ]
       ↓
[ Lookup template from this calendar (Google Sheets) ]
       ↓
[ Generate post text via GPT-4o-mini (template + today's date) ]
       ↓
[ Branch ]
   ├→ [ Post to X (Twitter API v2) ]
   ├→ [ Post to Threads (Meta Graph API) ]
   └→ [ Save to PostgreSQL for analytics ]
```

このカレンダーをGoogle Sheetsにコピーし、n8nのSchedule Trigger → Google Sheets Lookup → OpenAI → 各SNS API で自動投稿可能です。
