# AI占い LINE Bot サブスク事業 ローンチ計画

> 目標：3か月以内に月次黒字、6か月で月商30万円、12か月で月商100万円のストック収益化。

## 0. なぜAI占いか

- **市場規模**：国内占い市場は約1兆円、リピート率が極めて高い（恋愛・キャリア・人間関係の悩みは無限供給）
- **AI親和性**：占術ロジックは「ルール × ナラティブ生成」で、まさにLLMが得意な領域
- **自動化適性**：ユーザー入力 → 占術エンジン → 鑑定文生成 → 課金 → 配信、まで完全フロー化可能
- **継続課金性**：日々の運勢・週次鑑定でサブスク化が自然
- **競合の質が低い**：既存LINE占いの多くは人力／テンプレ／高額単発で、AIによる「無制限プレミアム」は空白地帯

## 3. 占術エンジン設計（LLMプロンプト構成）

### 3-1. プロンプト3層構造

```
[システムプロンプト]
  - 占い師ペルソナ（口調・専門性）
  - 安全性ガイドライン（断定回避・医療/法律助言禁止）
  - 出力フォーマット（見出し・絵文字・文字数）

[占術ロジック層]
  - 西洋占星術: 出生天体配置 → 各ハウスの意味解説
  - タロット: 引いたカードの正逆位置 + スプレッド位置の意味
  - 数秘術: 数字計算結果 + 各数字の象徴
  - 四柱推命: 命式 → 五行バランス → 通変星

[ユーザー入力層]
  - 質問文
  - 過去の鑑定履歴（コンテキスト維持）
  - 課金プラン（出力ボリューム制御）
```

### 3-2. 占術計算は決定論的に
LLMに天体計算をさせると不正確 → 計算はライブラリ、解釈のみLLM
- 西洋占星術：`pyswisseph`（Swiss Ephemeris）
- 四柱推命：`sxtwl`（中国天文暦）
- タロット：Random.org or crypto.randomInt（公平性担保）

### 3-3. ハルシネーション対策
- 占術ロジック層の出力をJSON化 → LLMには「この結果を◯◯字で物語化して」とだけ指示
- 「絶対」「必ず」「100%」を禁止語リスト化、出力後に検閲
- 医療・法律・自殺関連トリガで専門機関誘導文に強制差し替え

## 6. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| LINE規約違反（占いカテゴリ） | アカウント凍結 | 「エンタメ」表記徹底、断定表現排除 |
| 景品表示法（優良誤認） | 行政指導 | 「絶対当たる」「必ず」を禁止語、エビデンスなき効果訴求NG |
| 個人情報保護法 | 行政処分 | 出生情報は暗号化保存、退会時即削除、プラポリ明記 |
| OpenAI API値上げ | 粗利率低下 | GPT-4o-miniメイン、Claude HaikuやGemini Flashへフェイルオーバー |
| 競合参入 | 価格競争 | ペルソナ・占術ロジック・SNS資産で差別化 |
| LLMハルシネーション | 信頼失墜 | 計算は決定論的、出力検閲、危険トリガで専門機関誘導 |
| 課金トラブル | チャージバック | Stripeダッシュボードでアラート、無料体験7日設定 |
| サブスク解約率 | LTV低下 | デイリープッシュでエンゲージ維持、誕生日特典 |

### 特に注意：占い業の法規制
- 占い業は「電話占い」型でも特定商取引法対象外だが、**特商法表記（事業者名・住所・連絡先・解約方法）は必須**
- 「鑑定結果に基づく投資助言」「医療行為の代替」は法令違反になり得る
- 「霊感商法」とみなされる開運グッズの押し売りはNG（消費者契約法）
